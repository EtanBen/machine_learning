# Reconnaissance de chiffres manuscrits

Projet scolaire de 3e année (Polytech Nice-Sophia) : classer des chiffres manuscrits avec du machine learning, sur le jeu de données `digits` de scikit-learn (images de 8×8 pixels, 10 classes).

## Contenu

- `01_exploration_pca.py` : exploration des données, ACP, création de variables (zones, contours)
- `02_svm_pipeline.py` : pipeline scikit-learn, SVM, recherche d'hyperparamètres
- `03_reseau_neurones.py` : réseau de neurones avec Keras

## Lancer

```bash
pip install numpy pandas matplotlib seaborn scipy scikit-learn scikit-image tensorflow
python 01_exploration_pca.py
```

## Outils

Python, scikit-learn, TensorFlow/Keras, pandas, NumPy, Matplotlib.
